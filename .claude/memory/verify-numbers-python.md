2026-07-07。ユーザから「計算ミスをしていないか気がかり」「Pythonの計算機で計算し直して」と指摘され、実際に2つの過大表現が見つかった:
- 加算性の一致誤差を「0.5%」と報告 → 正しくは **0.75%**(生データ再計算)。
- 有意性を「差はsdの4〜15倍」 → 正しくは **約3.6〜8倍**。

**Why:** ユーザは研究者で、報告数値の正確さを厳しく見る。丸めの甘さや"良く見せる方向"のズレは信頼を損なう。

**How to apply:** 実験結果の平均・%・sd・比などを報告する前に、**生CSVからPythonで再計算して照合**する(その場の暗算や概算で出さない)。特に「◯倍」「誤差◯%」のような効果サイズ・有意性の表現は要検算。ズレていたら**正直に訂正**し、盛らない。指標の定義式(例 softirq/req=(負荷−基線)/rps×1000)も生cores値から再現して一致を確認すると安心される。
